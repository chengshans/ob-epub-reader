## EPUB Marginalia 1.3.42

相较 **1.3.41** 的更新：

### 新增
- **触屏翻页**：分页模式下轻触左右边缘或横向滑动即可翻页，适合平板 / 手写笔场景；鼠标仍使用滚轮、方向键与工具栏按钮
  - 拖选文字、点中真实链接或已有标注、多指操作时不翻页
  - 边缘轻触延迟 260ms，避让双击选词
  - 按 `page-progression-direction` 适配从右往左（RTL）排版的书籍
- **摘录文件名占位符 `{filenameNoExt}`**：不含 `.epub` 扩展名的文件名，如 `{filenameNoExt}-notes.md` → `demo-notes.md`
  - `{title}`、`{filename}` 行为保持不变

### 修复
- **整章正文变蓝（看似整章高亮）**：部分 EPUB 章节缺少 XHTML 命名空间，空元素被序列化成自闭合标签；iframe 按 HTML 解析时，空的 `<a/>` 会把后续整章内容变成自己的子节点，并被主题渲染为链接色
  - 非 void 自闭合标签统一展开为成对标签，同时避免 `<span/>` 等造成的 CFI 偏移
  - 仅带 `href` 的真实链接使用链接色
- **摘录标题 / 文件名重复书名号**：书名自带《》等书名号时，默认模板会生成 `# 《《国富论》》摘录` / `《《国富论》》摘录.md`，现统一合并为一层
  - 书名匹配同时忽略外层书名号，避免去重后找不到原书
- **旧摘录文件自动迁移**：去重后摘录文件名变化，首次访问时把旧文件改名到新路径，保留已有标注与阅读进度
